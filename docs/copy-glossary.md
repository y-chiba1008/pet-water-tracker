# 用語集・文言スタイルガイド

新しい UI 文言を追加・修正するときは、このドキュメントに合わせてください。

---

## 1. ドメイン用語

| 概念 | 表記 | 使わない / 避ける | 備考 |
|---|---|---|---|
| アプリ名 | 猫の飲水量記録 | — | `AppShell` / ログイン / `index.html` で共通 |
| 水皿マスタ | 水皿 | お皿（ユーザー向け） | ヘルパー文でも「水皿」に揃える |
| ナビ・画面：交換記録 | 水皿交換 | — | 画面タイトル・ナビと一致 |
| ナビ・画面：個別記録 | 個別給水 | — | 画面タイトル・ナビと一致 |
| ナビ・画面：マスタ管理 | 水皿管理 | — | |
| ナビ・画面：ホーム | ホーム | — | |
| ペットが飲んだ量 | 飲水量 | 給水量（ユーザー向け） | グラフ・個別記録・集計で使用 |
| 皿に入っている / 入れる量 | 容量 | — | 「新しい容量」「残った容量」 |
| 交換〜次の交換の1区間 | （ユーザー向けに出さない） | サイクル | ユーザー向け文言から完全に排除する。コード・コメント・DB 用語としての `cycle` は残してよい |
| 論理削除 | 削除 | 登録解除 | UI 操作名・ダイアログとも「削除」に統一 |

### 「サイクル」の言い換え

| 現状 | 表記 |
|---|---|
| 給水サイクルを開始しました | 給水を開始しました。 |
| サイクルを終了しました | 給水を終了しました。 |
| 新しい給水サイクルを開始します | 新しい給水を開始します。 |
| 空欄のまま保存すると、サイクル終了のみ記録します（片付け）。 | 空欄のまま保存すると、終了のみ記録します（片付け）。 |

## 2. 日付・時刻

| 概念 | 表記 | 使わない | 備考 |
|---|---|---|---|
| 当日 | 今日 | きょう / 本日 | カード・グラフ軸・一覧ラベルで統一 |
| 当月 | 今月 | 当月 | カレンダー操作も「今月」「今月へ」 |
| 時刻 | `HH:mm`（例: `11:30`） | — | |
| 別日の日付+時刻 | `M/d HH:mm`（例: `9/18 11:30`） | — | |
| カレンダー月見出し | `yyyy年 M月` | — | |
| 入力欄ラベル | 日時 | 時刻のみ、など | 必須マーク付き |
| 現在時刻セット | 現在時刻にする | — | |
| 前回の記録を指す語 | 前回の記録 | 直近の記録 / 直近の完了 / 直近記録 / 前回の給水記録 | 一覧・サマリー・フォームで統一 |

### 「前回の記録」の用例

| 用途 | 表記 |
|---|---|
| 水皿一覧の完了時刻 | 前回の記録: 今日 HH:mm / 前回の記録: M/d HH:mm |
| ホームのサマリー | 前回の記録 HH:mm |
| 水皿交換フォーム | 前回の記録 |

### 経過時間

「約」は付けない。

| 用途 | 表記 |
|---|---|
| フォームの経過表示 | 8時間 / 30分 / 2日 など |
| 一覧の経過表示 | 交換から8時間経過 |

### グラフ期間

| 用途 | 表記 |
|---|---|
| タイトル・注釈 | 直近30日間 |
| バッジ | 30日間 |

タイトルとバッジは同じ語に揃える（`1ヶ月` は使わない）。

## 3. 容量・単位

| 項目 | 表記 | 備考 |
|---|---|---|
| 数値+単位 | `{n}ml`（スペースなし） | 例: `200ml`。Tooltip も同じ |
| 単位だけの補助表示 | `ml` | サマリーカードなど |
| 軸・凡例の単位注記 | `(ml)` | 例: `日別合計飲水量 (ml)` |
| 加算プリセット | `+10ml` | 個別給水のみ（加算であることが分かるため `+` 可） |
| 絶対量プリセット | `50ml` | 水皿交換側 |

### フィールド名とバリデーションの対応

| フィールド | ラベル | 未入力メッセージ |
|---|---|---|
| 個別給水の量 | 飲水量 | 飲水量を入力してください。 |
| 水皿の開始量 | 新しい容量 | 新しい容量を入力してください。 |
| 水皿の終了量 | 残った容量 | 残った容量を入力してください。 |
| 水皿名 | 水皿の名前 | 水皿の名前を入力してください。 |

「容量」＝皿の中の量、「飲水量」＝飲んだ量、という役割分担は維持する。

## 4. メッセージ定型

### 失敗（句点あり・リカバリ文あり）

パターン:

```text
{対象}に失敗しました。もう一度お試しください。
```

| 場面 | 文言 |
|---|---|
| 保存全般 | 保存に失敗しました。もう一度お試しください。 |
| 削除 | 削除に失敗しました。もう一度お試しください。 |
| ログイン | ログインに失敗しました。もう一度お試しください。 |
| 水皿一覧の取得 | 水皿一覧の取得に失敗しました。もう一度お試しください。 |
| 水皿交換用データの取得 | 水皿記録データの取得に失敗しました。もう一度お試しください。 |
| 集計の取得 | 集計データの取得に失敗しました。もう一度お試しください。 |

取得失敗の対象名は画面の意味が分かる範囲で具体名を付ける（曖昧な「データ」単独は避ける）。

使わない例:

- `時間をおいて再度お試しください。`（リカバリ文のゆれ）
- リカバリ文なしの短い取得エラーのみ

### 成功（句点あり）

| 場面 | 文言 |
|---|---|
| 給水開始 | 給水を開始しました。 |
| 給水終了（片付け） | 給水を終了しました。 |
| 交換（終了+開始） | 水皿の交換を記録しました。 |
| 個別記録 | 飲水量 {n}ml を記録しました。 |

### ログイン拒否など

| 場面 | 文言 |
|---|---|
| 許可外アカウント | このアカウントではログインできません。 |

## 5. ボタン・操作

| 種類 | 表記 | 備考 |
|---|---|---|
| 取得失敗後の再実行 | 再読み込み | |
| 取り消し（全ダイアログ共通） | キャンセル | 追加・編集・破壊的確認いずれも統一。見た目クラスは AGENTS.md の取り消しスタイル |
| 主アクション（ダイアログ） | 〜する（例: 保存する / 削除する / 水皿を追加する） | |
| 一覧の短い CTA | 体言止め可（例: 水皿を追加） | |
| 記録フォーム送信 | 記録を保存する | |
| 進行中 | `保存中…` / `削除中…` / `読み込み中…` / `ログアウト中…` | 三点リーダは全角 `…`（半角 `...` は使わない） |
| 論理削除の確定 | 削除する | |

### 削除ダイアログ

| 要素 | 表記 |
|---|---|
| タイトル | 水皿を削除しますか？ |
| 本文 | 「{名前}」を削除します。過去の飲水量ログは保持されます。 |
| 確定ボタン | 削除する |
| 取り消し | キャンセル |

## 6. ステータス

| 概念 | 表記 |
|---|---|
| 進行中の給水あり | 設置中 |
| 進行中の給水なし | 待機中 |
| 記録が無い表示 | 記録なし |
| 空状態タイトル | 水皿がまだありません |

空状態の誘導文は画面に応じて具体化するが、トーンは揃える:

| 画面 | 表記 |
|---|---|
| 水皿管理 | 「水皿を追加」から最初の水皿を登録してください。 |
| 水皿交換 | 先に水皿管理から水皿を登録してください。 |

## 7. 文体・句読点・記号

句点の有無は「文章形式かどうか」で決める（ラベル・バリデーション共通）。

| 種類 | ルール | 例 |
|---|---|---|
| 文章形式のラベル・ステータス説明 | 句点 `。` あり | 新しい給水を開始します。 |
| 体言・短いラベル | 句点なし | 設置中 / 待機中 / 記録なし / 日時 |
| バリデーション（文章形式） | 句点あり | 日時を入力してください。 / 新しい容量を入力してください。 |
| エラー・成功トースト | 句点あり | 保存に失敗しました。もう一度お試しください。 |
| ヘルパー・説明文 | 句点あり | 水皿の交換日時として記録されます。 |
| グラフ注釈など補足 | 句点あり | 直近30日間の合計値を自動集計しています。 |
| 省略記号 | 全角 `…` | 読み込み中… / 認証画面へリダイレクト中… |
| 空値ダッシュ | `—` | 前回の記録 — |
| 計算式のマイナス | `−`（数学記号） | 200ml − 50ml |

ログインのキャッチコピー（「水分補給」など）はマーケティング文としてドメイン用語と完全一致しなくてよい。ただしブランド名は「猫の飲水量記録」で固定。
