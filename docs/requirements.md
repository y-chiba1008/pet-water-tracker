# ペット飲水量記録アプリ 要件定義書

## 1. 概要

猫（1匹）の飲水量を記録・可視化するためのWebアプリケーション。
複数の水皿を管理でき、水皿の交換前後の容量差分から飲水量を算出する「水皿記録」と、直接飲ませた水の量を記録する「個別記録」の2種類の記録手段を持つ。

## 2. 対象ユーザー

- 事前登録された2名のみ
- Google アカウントによるSSOログイン
- 全ユーザーで情報（猫・水皿・記録）を共有する（ユーザーごとの情報分離は行わない）

## 3. 機能要件

### 3.1 水皿記録

- 水皿は複数管理可能。各水皿ごとに独立して記録する。
- 「交換〜交換までの1サイクル」を1レコードとして管理する。
  - カラム: 水皿ID、開始時刻、開始容量、終了時刻、終了容量、記録者
  - 開始容量・開始時刻＝交換直後（水皿を満たした直後）の値
  - 終了容量・終了時刻＝次の交換直前の値
  - 1サイクルの飲水量 ＝ 開始容量 − 終了容量
  - 終了容量が開始容量より大きい場合は異常値として警告を表示する
- 記録操作のルール
  - 対象水皿に「進行中サイクル」（終了時刻が未入力のレコード）が存在するかどうかで、入力可能な項目が切り替わる。
  - **進行中サイクルがない場合**：「開始容量・開始時刻」のみ入力可能。新規レコードをinsertする。
  - **進行中サイクルがある場合**：
    - 「終了容量・終了時刻」のみ入力 → 進行中レコードをupdateするのみ（新規レコードは作成しない。水皿を一時的に片付けている状態などに対応）
    - 「終了容量・終了時刻」と「開始容量・開始時刻」を両方入力 → 進行中レコードをupdateし、同時に新規レコードをinsertする（通常の水皿交換操作）
  - 過去の時刻を指定した事後入力を許可する。記録漏れの補完はユーザー側で行う想定とし、システム側での欠損検知・警告は行わない。

### 3.2 個別記録

- 単発のイベントとして記録する（時刻、量、記録者）。
- 日次集計値としての直接入力は行わない。

### 3.3 飲水量の集計・可視化

- 日別の飲水量合計 ＝ その日に属する水皿記録の飲水量 ＋ その日の個別記録の合計
  - 水皿記録は「終了時刻」の属する日付で集計する。
- 表示形式
  - カレンダー表示：日毎のセルに合計飲水量（数値）を表示する。色分けや目標量に対する達成度表示は行わない。
  - 折れ線グラフ表示：直近1ヶ月固定で表示する（期間選択機能は持たない）。
- 水皿記録と個別記録を分けた内訳表示は行わない（合計値のみ）。

### 3.4 水皿管理

- 水皿の新規登録、一覧表示、編集を行う。

### 3.5 記録の入力精度

- 容量の入力単位は1ml。

### 3.6 認証・ユーザー管理

- Google アカウントによるSSOログイン。
- Supabase上でユーザー（2名分）を事前に手動作成しておく。
- Supabaseの設定で新規サインアップを禁止し、事前登録されたユーザー以外がアカウントを作成・ログインできないようにする。

## 4. 画面構成

| # | 画面名 | 概要 |
|---|---|---|
| 1 | ログイン画面 | Googleアカウントでのログインボタンのみ |
| 2 | ホーム画面 | 可視化画面。カレンダー表示と折れ線グラフ表示を切り替え可能 |
| 3 | 水皿記録画面 | 水皿を選択し、状態（進行中サイクルの有無）に応じて入力欄が切り替わるフォーム |
| 4 | 個別記録画面 | 飲ませた水の量・時刻を入力する単発フォーム |
| 5 | 水皿管理画面 | 水皿の一覧、新規登録、編集 |

- 水皿記録画面と個別記録画面は別画面とする。
- 記録の生ログを一覧表示する画面は今回のスコープに含めない。

## 5. 技術構成

- フロントエンド: React
- バックエンド: Supabase（DB、認証）

## 6. 今回のスコープ外（将来拡張候補）

- ユーザーの新規登録機能
- 「家」単位の共有設定（猫・水皿・ユーザーが「家」に所属し、ユーザーは自分の所属する家の情報のみアクセス可能とする仕組み）
- 猫の複数管理
- 記録の事後修正・削除機能
- 複数ユーザーによる同時編集の考慮（排他制御など）
- 水皿記録と個別記録の内訳を分けた可視化
- 日付をまたぐ水皿記録サイクルについて、飲水量を時間比で按分して日別集計に反映する改修
  - 例: 1/1 20:00 〜 1/2 21:00（25時間）のサイクルで飲水量50mlの場合、時間比で按分し、1/1は8ml、1/2は42mlとして日別集計に計上する
  - 現時点では上記の按分は行わず、「終了時刻」の属する日付にサイクル全体の飲水量を計上する簡易ロジックとする（3.3節参照）
